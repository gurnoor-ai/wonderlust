# 🌍 Wanderlust — Travel & Tourism Website

A modern and responsive travel and tourism website built as part of my **Web Application Internship – Week 2**.

The project demonstrates the fundamentals of frontend development using **HTML, CSS, and JavaScript**.

---

## 📌 Project Overview

**Wanderlust** is a travel website designed to help users explore popular destinations, view travel packages, browse travel images, and send enquiries through a contact form.

The website focuses on:

- Clean and simple UI
- Responsive design
- Smooth animations
- Interactive buttons
- Basic form validation
- Organized frontend project structure

---

## ✨ Features

### 🏠 Hero Section
- Travel-focused landing section
- Attractive background image
- Explore Destinations button
- View Packages button

### 🌍 Popular Destinations
Includes:
- 🇫🇷 Paris
- 🇦🇪 Dubai
- 🇮🇩 Bali
- 🇮🇳 Manali

### ✈️ Travel Packages
Each package includes:
- Destination
- Duration
- Rating
- Price
- Package features
- Book Now button

### 📸 Travel Gallery
- Destination images
- Image hover effects
- Responsive gallery layout

### 📩 Contact Form
Includes:
- Name
- Email
- Message
- Required-field validation
- Email format validation

### 📱 Responsive Design
The website is designed to work on:
- Mobile phones
- Tablets
- Laptops
- Desktop computers

### 🎨 Animations
- Page loading animation
- Hero text animations
- Button hover effects
- Card hover effects
- Image zoom effects
- Smooth scrolling
